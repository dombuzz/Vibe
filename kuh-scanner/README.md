# Kuh-Scanner 🐄

Scherz-App: Ohrmarke fotografieren (oder Nummer tippen) – die App gibt der Kuh einen zufälligen Namen.
Dieselbe Nummer bekommt immer denselben Namen; die «Datenbank» ist der localStorage des Browsers.

Nutzung: `index.html` auf dem Handy im Chrome öffnen → «Zum Startbildschirm hinzufügen».
Texterkennung via Tesseract.js (CDN) bzw. TextDetector, sonst Nummer von Hand eintippen.
